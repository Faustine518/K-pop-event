# SEOUL SIGNAL · 韩国活动雷达

## 启动

安装 Node.js 22 或更新版本，双击 `启动网站.cmd`，保持命令窗口开启。浏览器访问 http://127.0.0.1:4173 。无需 npm install。也可在此目录运行 `npm start`。

## 首次设置（重要）

本交付不包含虚构或未经核实的活动。初始列表为空。自动采集当前仅实现首尔文化门户，不覆盖全部韩国、社交平台或偶像公告。

在 [首尔开放数据](https://data.seoul.go.kr/dataList/OA-15486/S/1/datasetView.do) 申请文化活动 API 密钥（来源：首尔市，公公共利第一类，须标明来源）。PowerShell 中执行：

```powershell
$env:SEOUL_API_KEY='你的密钥'
node server.mjs
```

环境变量仅保留于当前窗口；长期使用可通过 Windows 环境变量设置界面添加后重新启动。密钥不会传给浏览器。上游网络或接口失败会保留旧数据并记录错误。接口实网采集尚未验证，需要有效密钥验证。

## 更新方式

服务启动时检查韩国日期，当日未尝试更新会补更；运行中每分钟检查，每个韩国自然日自动尝试一次。立即更新按钮可随时重试，无需重建。电脑关闭期间不执行，下一次启动补更。默认不安装 Windows 定时任务，不要求全天在线。

更新按来源稳定 id 合并，保留未再次出现的活动。上游列表消失不等于取消；取消、延期和费用变动需要查看原公告，可用相同 id 导入修订。自动数据的“已收录”只表示官方接口返回，不代表预约尚有名额。未提供或不可解析费用按未知处理，不纳入免费/低价筛选。

## 搜索与手动数据

管理页提供 Naver 韩语查询和官方入口。按城市、月份与类别调整关键词，如 `부산 2026 11 무료 공연 사전예약`、`서울 팝업 스토어 예약`、艺人名加 `쇼케이스 공개방송 컴백 공지`。先广泛发现，再核对主办方公告；不要把粉丝推测当官宣。核对时间、地点、费用、年龄/外国人限制、申请截止及取消状态后导入。

JSON 文件须为数组；下面仅是字段说明，不能当作真实活动导入：

```json
[{"id":"主办方稳定唯一编号","title":"官方标题","city":"釜山","start":"2026-11-20","end":"2026-11-20","categories":["K-pop","现场演出"],"price":0,"fee":"免费，须预约","venue":"公告中的场地","requirements":"身份证明、年龄要求等","deadline":"申请截止时间（韩国时间）","source":"https://主办方公告地址","booking":"https://官方预约地址","status":"已确认","description":"经核实的说明"}]
```

费用未知用 `null`，不要推测为免费。回归资讯增加 `"kind":"comeback"`，会只在回归月历显示。活动可有多个类别（现场演出、K-pop、展览文化、快闪品牌）。改期保留原 id 并修改日期；取消保留 id 并将 status 改为“已取消”。同一活动不同来源需人工使用同一个 id 去重，接口内部按标题、日期和场馆生成 id，标题或日期修改可能需人工合并。

数据保存在 `data/store.json`；导出按钮备份活动数组。复制整个目录可迁移更新日志和设置之外的全部数据。页面显示最近尝试结果；每条活动保留采集/导入时间，该时间不代表人工复核。

## 运行边界

仅监听本机 127.0.0.1。不要把服务直接暴露公网。当前仅支持单个服务进程。无外部依赖、无付费检索、无后台 AI API；自动发现的覆盖率有限。釜山、快闪和回归资讯需人工补充，没有实现无人值守社交媒体搜索。源码通过 GitHub 插件提交至 Faustine518/K-pop-event。

## GitHub Pages 与 Actions

仓库包含自动部署工作流。若部署提示权限不足，在 Settings → Pages 将 Source 设为 GitHub Actions，然后在 Actions 运行 Publish website。每天韩国时间约 08:17 自动采集（GitHub 调度可能延迟）；手动更新按钮进入 Actions，登录后点击 Run workflow。请在 Settings → Secrets and variables → Actions 添加 SEOUL_API_KEY。未设置时更新日志明确报错。Pages 为静态网站，导入数据保存在当前浏览器；跨设备共享请将核实数据合并进 data/store.json。不要在公开仓库提交密钥或个人报名信息。
